## ADDED Requirements

### Requirement: Modern UI V2 and Classic Web Client
The system SHALL deliver a responsive web workspace with 17 canonical views (Dashboard, Processes, Publications, Tasks, Agenda, Contacts, Leads, Financial, Documents, Prompts, Assistant, Judicial Integrations, Audit, Monitoring, Importer, Links, Configuration) with seamless switching between UI V2 and UI Classic.

#### Scenario: Navigating Canonical Views
- **WHEN** user selects any of the 17 legal workflow views in UI V2
- **THEN** view renders with accessible theme tokens, responsive layout, and reactive store updates
